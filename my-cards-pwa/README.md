# My Cards — PWA

Файлы:
- `index.html` — само приложение
- `manifest.webmanifest` — название, иконка, цвета для установки
- `sw.js` — офлайн-режим
- `icons/` — иконки

## Как выложить на GitHub Pages (бесплатно)

1. Зарегистрируйтесь на https://github.com (если ещё нет аккаунта).
2. Нажмите «+» → **New repository**. Название, например, `my-cards`. Выберите **Public**, нажмите **Create repository**.
3. На странице репозитория нажмите **uploading an existing file** и перетащите все файлы из архива (вместе с папкой `icons`). Нажмите **Commit changes**.
4. Откройте **Settings → Pages**. В разделе *Build and deployment* выберите *Source: Deploy from a branch*, ветку `main`, папку `/ (root)`, нажмите **Save**.
5. Через 1–2 минуты появится адрес вида `https://ВАШ-ЛОГИН.github.io/my-cards/`.

## Установка на телефон

- **Android (Chrome):** откройте адрес → меню (⋮) → **Установить приложение**.
- **iPhone (Safari):** откройте адрес → **Поделиться** → **На экран «Домой»**.

Откройте приложение один раз с интернетом — после этого оно работает и офлайн.

## Важно

- Карты хранятся в памяти телефона. Время от времени нажимайте **Backup → Save backup file**, а на новом телефоне — **Restore from file**.
- Карты из версии на claude.ai автоматически не переносятся: их нужно добавить заново.
- Если меняете файлы, увеличьте `VERSION` в `sw.js` (например, `my-cards-v2`), чтобы телефон получил обновление.
